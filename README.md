# Neoeter Python

CPython 2.7 host and Python bindings for the OpenMT2 client.

Headers are included as `<Neoeter/Python/Host/...>` and
`<Neoeter/Python/Bindings/...>`. The engine is consumed through its
`Neoeter::*` targets and `<Neoeter/...>` headers.
